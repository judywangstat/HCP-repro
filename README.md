# Reproducibility Materials

This repository contains reproducibility materials for the paper:

**Hierarchical Conformal Prediction for Clustered Data with Missing Responses**

It includes all code and data required to reproduce the simulation studies and real-data analyses presented in the paper.

---

## Repository structure

- data/  
  Input datasets used in the real-data analysis, including the CD4 dataset and the gallstones dataset.

- R/  
  Core functions used across simulations and real-data experiments. This includes implementations of the proposed HCP method, benchmark methods (DWR, LC, LMEM, Oracle), data-generating processes, and evaluation utilities. Detailed descriptions of each function are provided in `R/README.md`.

- simulation/  
  Scripts to reproduce all simulation results (tables and figures). A detailed description of each script is provided in `simulation/README.md`.

- real_data/  
  Scripts to reproduce real-data results (tables and figures). A detailed description of each script is provided in `real_data/README.md`.

- results/  
  Output files generated by the scripts, including tables (CSV) and figures (PDF). All main results from the paper are provided here.

## How to reproduce the results

### Quick check

All results reported in the paper are already provided in the `results/` folder.

---

### Step 1: Set repository path

Each reproducibility script in the `simulation/` and `real_data/` folders defines a local repository path near the top of the file. For example:

repo_dir <- normalizePath("~/Desktop/HCPclust-repro", mustWork = TRUE)

Before running a script, please modify `repo_dir` to the local path where this repository is stored. For example:

repo_dir <- normalizePath("/path/to/HCPclust-repro", mustWork = TRUE)

All input files are read from subfolders of `repo_dir`, and all generated results are saved to the `results/` folder.

---

### Step 2: Run the corresponding script

All scripts are self-contained and can be run independently. To reproduce a specific table or figure, run the corresponding script listed below.

For example, to reproduce Table 1:

1. Open `simulation/reproduce_table1.R`
2. Update `repo_dir` near the top of the script
3. Run the script in R or RStudio
4. The output will be saved to `results/table1_final_results_missing20.csv`

For figures, first run the corresponding data-generation script and then run the plotting script. For example, to reproduce Figure 2:

1. Run `real_data/reproduce_figure2_cd4_data.R`
2. Run `real_data/plot_figure2_cd4.R`
3. The output will be saved to `results/figure2_cd4_band.pdf`

Detailed descriptions of all scripts are provided in `simulation/README.md` and `real_data/README.md`.
